# Rank Up: FRC 2658 Software Training

This repo holds the starter project for every rank in the software subteam's rank-up system.

**Everything you need to do lives in the [Rank Up Projects guide](https://claude.ai/code/artifact/5fdfb435-43a4-4db4-90f5-c843171497ee).** Open the tab for your rank and follow it step by step. Start with the **Start here** tab.

## Ranks

| Rank | Robot track | Web track |
| --- | --- | --- |
| Unranked | Git (everyone) | Git (everyone) |
| Copper | Joystick Direction Decider | Student Filter |
| Iron | Motor Ramp Simulator | Typed Student Tracker |
| Gold | Mock Robot Hardware | Attendance Card |
| Platinum | Bench Motor Control | Attendance Dashboard |
| Diamond | Simple Motor Subsystem | Attendance App |
| Emerald | Arm to Presets | First PR in nautilus-frontend |
| Ruby | Contributing to Rebuilt-2026 | Own a feature in nautilus-frontend |

## Folders

```
unranked/     the Unranked assessment, edited in place by everyone
templates/    one starter project per rank (don't edit these)
students/     your copies go here: students/<username>/<track>/<rank>/
bonus/        optional challenges
REVIEWING.md  for leads: what to look for at each rank
```

There's no auto-grader. A lead reviews every PR by hand, running the code and asking you to explain it.
